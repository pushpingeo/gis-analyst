How to read this

Agreement is the share of yes/no calls that match IFC's. Because IFC applies PS5 and PS6 to most projects, saying yes to everything already scores well on those, so compare against that column. Kappa is the fairer measure. It corrects for agreement you'd get by chance: 0 means no better than guessing, 1 means perfect. Consistency is how often repeated runs on the same site give the same answer. Flag recall asks the question that matters for a screening tool: for each standard IFC applied, did at least one of the agent's flags point to it? Evidence traceable is the share of features the agent cites (by name and distance) that can be found in what the tools actually returned; the rest are paraphrased, translated or invented.

The four set-ups: Rules only applies the skill's distance rules mechanically, with no AI. Skill off is Claude with the same tools but no method. Skill on adds the NTR skill. Skill + web also lets it search the web.

What keeps it honest. The agent never sees the project name or IFC's answer. Web search blocks IFC's and other lenders' disclosure sites, and any run whose searches turn up the project's name is flagged as a leak and scored both with and without. Some hindsight can't be removed: today's web knows what happened after IFC's decision.

Limits. IFC's calls rest on field surveys and project design as well as location, so 100% isn't the target. PS7 (Indigenous Peoples) is triggered for only a few projects in the set, so its numbers are fragile.
